# Gemini ট্যাব ওয়ার্কফ্লো (Claude in Chrome) — ২০২৬-১০-১৮

Claude নিজে কাজ ঠিক করে, ৪টি Gemini ট্যাবকে (সবাই সমান অ্যাসিস্ট্যান্ট, সিনিয়র নেই) জিপ পাঠায়, উত্তর নিয়ে প্রজেক্টে বসায়, টেস্ট করে, পরের কাজ দেয়।
ব্রাউজার: "Browser 1" (deviceId 6700429a-c905-4ecb-9f88-3f2c68ac2365)। পুরনো bridge এক্সটেনশন এই পিসিতে নেই — ব্যবহার করবে না।

## প্রতি ট্যাবে ধাপ (মানুষের মতো ধীরে, এক ট্যাব শেষ করে পরেরটি; ধাপের মাঝে কয়েক সেকেন্ড বিরতি)
1. `tabs_context_mcp {createIfEmpty:true}` → নতুন ট্যাবে `https://gemini.google.com/u/0/app`।
   - **URL-এ authuser/u/N দিয়ে অ্যাকাউন্ট বদলাবে না** — Google CAPTCHA ("sorry" পাতা) দেয়।
2. অ্যাকাউন্ট: নিচে-বামে প্রোফাইল (Fayzar Backup) → তালিকা থেকে অ্যাকাউন্ট ক্লিক।
   অ্যাকাউন্ট: fayzarbackup (Pro, ডিফল্ট), fayzarbackup1, 2, 3, 4, 6, 7, 8। লিমিট এলে পরেরটিতে যাও।
3. ইনপুটের নিচে **Chat → Task** নির্বাচন।
4. মডেল-মেনু (ইনপুটের ডানে "Pro ⌄") → **Gemini 4 Argon**।
5. ফাইল আপলোড (নেটিভ পিকার খোলা যায় না, তাই):
   - JS দিয়ে পেজে `<input type=file id=cc-file-inject aria-label="cc file inject">` যোগ → `find` দিয়ে ref → `file_upload`
     (পাথ scratchpad-এর `out\` ফোল্ডারে কপি করা জিপ)।
   - JS: `DataTransfer`-এ ফাইল রেখে `rich-textarea .ql-editor`-এ `paste` ClipboardEvent → input মুছে ফেলো → প্রিভিউ আসা পর্যন্ত অপেক্ষা।
6. চ্যাটে শুধু এক লাইন: "সংযুক্ত জিপের PROMPT.md অনুযায়ী কাজ করুন।" → আপলোড শেষ হলে **Send** বাটন ক্লিক (Enter নয়)।
   সব দায়িত্ব/নির্দেশনা জিপের PROMPT.md-তে — চ্যাটে বাড়তি কথা নয়।
   **নিয়ম:** Gemini-র কাছ থেকে শুধু একটি জিপ ফাইলই নেওয়া হবে। প্রতিটি PROMPT.md-তে "উত্তর দেওয়ার কঠোর নিয়ম" অংশ থাকতে হবে
   (পুরো উত্তর = একটি ডাউনলোডযোগ্য জিপ; ব্যাখ্যা/প্রশ্ন/ফল সব README.md-তে; চ্যাটে কিছু লেখা নিষেধ)। নতুন প্রম্পট লিখলে এই অংশ হুবহু কপি করো।
   ফল/পরের কাজ পাঠানোর সময়ও একইভাবে জিপ (PROMPT.md + ফল) + এক লাইন।
   **আমাদের দিক থেকেও:** প্রম্পট + প্রয়োজনীয় ফাইল সব জিপে; চ্যাটে শুধু ওই এক লাইন, বাড়তি কথা নয়।
   **তাড়াহুড়া নয়:** প্রতিটি ধাপ ধীরে; এক ট্যাবে পাঠানো শেষ করে কিছুক্ষণ পর পরেরটি।
   **রিফ্রেশ:** কাজ দেওয়ার পর ৩–৫ মিনিট পরপর একটি করে ট্যাব রিলোড করে দেখো (ট্যাব প্রায়ই হ্যাং থাকে, কাজ শেষ হলেও দেখায় না)।
   একসাথে সব ট্যাব রিলোড নয় — পালাক্রমে একটি করে।
7. উত্তর: ট্যাব রিলোড করে দেখো; "[file-tag]" এলে আসল ডাউনলোডযোগ্য ফাইল চাও। ডাউনলোড → Downloads থেকে নাও।

## বসানো ও যাচাই
- বান্ডেল: `node tools/agent_manager.mjs bundle --task <ID> --files "<f1,f2>" --instruction-file scratch/bundles/prompts/<ID>.md`
- প্যাচ বসানোর আগে ব্যাকআপ; নতুন আচরণ `globalThis.__FZ_ON_<NAME>` সুইচে, ডিফল্ট আউটপুট অপরিবর্তিত।
- `node tests/run-all.mjs` (ভিত্তি: ১৮৭২ পাস / ০ ব্যর্থ) + Word পরীক্ষা (qa/ asis-score, measure-doc.ps1; কপি মাপতে আলাদা পোর্ট 3018)।
- ফল জিপে ভরে একই ট্যাবে পাঠাও, পরের কাজ দাও। docs/MULTI_AGENT_MANAGEMENT.md-এর ট্র্যাকার হালনাগাদ।
